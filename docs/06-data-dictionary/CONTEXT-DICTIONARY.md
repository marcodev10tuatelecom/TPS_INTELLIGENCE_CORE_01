# Context Dictionary

Context dimensions include TIME, LOCATION, REGION, NETWORK, STATION, CHANNEL, PROGRAM, AUDIENCE, DEVICE, EVENT, EDITORIAL, COMMERCIAL, REGULATORY, RIGHTS and OPERATIONAL.

TPS_CONTEXT stores a canonical context identity/type plus JSON payload for dimension-specific qualifiers. Frequently queried/authoritative dimensions may graduate to normalized columns/tables after measured need; JSON is not a substitute for canonical identity.
