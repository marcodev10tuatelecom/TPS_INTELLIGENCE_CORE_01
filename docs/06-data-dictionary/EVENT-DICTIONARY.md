# Event Dictionary

Initial event types: TRACK_STARTED, TRACK_FINISHED, CONTENT_STARTED, CONTENT_FINISHED, PROGRAM_STARTED, PROGRAM_FINISHED, AD_PLAYED, USER_CONNECTED, USER_DISCONNECTED, STREAM_FAILED, CONTENT_PUBLISHED, NEWS_CREATED, ENTITY_CHANGED, RELATION_CHANGED, AI_RECOMMENDATION_CREATED, AI_RECOMMENDATION_ACCEPTED, AI_RECOMMENDATION_REJECTED, POLICY_DENIED, FAILOVER_STARTED, FAILOVER_COMPLETED.

Events are append-oriented observations. Corrections use linked correction/supersession events when business history must be preserved.
