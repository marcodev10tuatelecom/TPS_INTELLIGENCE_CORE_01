# Audience Domain

Entities/concepts: AUDIENCE_SEGMENT, LISTENER/VIEWER identity where lawful/appropriate, SESSION, AUDIENCE_OBSERVATION, DEVICE_CLASS, REGION, AFFINITY_PROFILE.

Prefer aggregate/pseudonymous observation when personal identity is unnecessary. Data classification and retention apply before collection.

D3KA relations express POPULAR_IN, RECOMMENDED_FOR, AFFINITY_WITH and observed behavior contexts. Predictive affinity is not a verified fact and records model/version/confidence.
