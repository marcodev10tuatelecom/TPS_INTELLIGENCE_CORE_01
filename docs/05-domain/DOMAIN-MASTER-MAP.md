# Domain Master Map

Canonical domains: CORPORATE, ORGANIZATION, MEDIA_NETWORK, STATION, CHANNEL, PROGRAMMING, CONTENT, MEDIA_ASSET, MUSIC, VIDEO, COMMERCIAL, ADVERTISING, RIGHTS, AUDIENCE, EDITORIAL, GEOGRAPHY, OPERATIONS, KNOWLEDGE, AI, SECURITY.

Each domain defines canonical entity types, relation types, context dimensions, events, policies and API projections. Cross-domain relationships use D3KA rather than duplicating identity.

Examples: `NETWORK OWNS STATION`, `STATION BROADCASTS CHANNEL`, `PROGRAM SCHEDULED_ON CHANNEL`, `TRACK PLAYED_ON CHANNEL`, `CAMPAIGN TARGETS AUDIENCE_SEGMENT`, `RIGHT AUTHORIZED_FOR REGION`, `PERSON PRESENTS PROGRAM`.
