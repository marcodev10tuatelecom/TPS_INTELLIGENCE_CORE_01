# Rights and Licensing Domain

Entities: RIGHT, RIGHTS_HOLDER, LICENSE, CONTRACT, TERRITORY, REGION, CONTENT, STATION/CHANNEL.

A grant is qualified by subject/content, holder/grantor, beneficiary, allowed action, territory, platform, station/network, validity window, exclusivity, restrictions and source document.

Core relations: LICENSED_BY, AUTHORIZED_FOR, PROHIBITED_IN, AVAILABLE_IN, OWNED_BY.

Rights decisions are deterministic and time/context-sensitive. Unknown rights state is not interpreted as permission for protected use unless business policy explicitly defines that behavior.
