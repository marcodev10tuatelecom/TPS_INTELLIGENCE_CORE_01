# Business Process Map

## Programming
Plan network schedule -> apply station/local overrides -> validate rights/policies -> publish schedule -> execute/observe playout -> record events -> analyze outcomes.

## Content onboarding
Register canonical work/content -> identify people/rights -> register physical media assets/renditions -> extract metadata/transcripts -> create vectors -> attach provenance -> approve use.

## Advertising
Register advertiser/campaign/creative -> contract/rights/territory/window -> inventory eligibility -> policy/frequency checks -> placement decision -> play event -> reconciliation/audit.

## AI recommendation
Resolve context -> retrieve relational/graph/vector knowledge -> generate candidate/recommendation -> deterministic validation -> authorize/reject -> record decision/evidence.

## Knowledge stewardship
Detect duplicate/inconsistent entities -> propose merge/correction -> human/policy validation -> canonical update -> preserve supersession/provenance.
