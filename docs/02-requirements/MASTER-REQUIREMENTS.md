# Master Requirements Index

Requirement namespaces: BR (business), FR (functional), DR (data), AIR (AI), SR (security), PR (performance), OR (operations/recovery), API (interface), CR (compliance).

Every requirement has: statement, rationale, priority, acceptance criteria, owner, related ADRs, source files, tests and evidence.

Priority: P0 mandatory for safe production core; P1 required for first operational release; P2 planned extension.

The detailed requirement files in this directory are normative and feed TRACEABILITY-MAP.md.
