# Data Requirements

- DR-001 immutable canonical entity IDs.
- DR-002 stable canonical keys with lifecycle state.
- DR-003 relation records reference source/target/type/context.
- DR-004 business validity and recorded timestamps stored separately where relevant.
- DR-005 extensible attributes use JSON only when normalization is not semantically superior.
- DR-006 provenance/source records for imported/observed/inferred facts.
- DR-007 vectors store model/version/type/dimension/format metadata.
- DR-008 media assets store SHA-256 and technical metadata; raw media may be external.
- DR-009 rights and policy state is queryable by station/channel/region/time/content.
- DR-010 every domain fact class is classified D3KA-eligible or relational-only with rationale.
- DR-011 soft deletion/supersession preserves referential/history semantics.
- DR-012 no secrets, wallets or private keys in business tables or repository.
