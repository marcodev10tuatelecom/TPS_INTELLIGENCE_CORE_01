# Technology Validation Register

Each technology passes through states DOCUMENTED_BY_ORACLE -> VISIBLE_IN_SERVICE -> PRIVILEGE_PROVEN -> MINIMAL_RUNTIME_TEST_PASS -> PERFORMANCE/SECURITY_VALIDATED -> CERTIFIED.

Initial rows:
- Relational SQL/PLSQL: Oracle documented; runtime gate pending repository-specific proof.
- SQL Property Graph/GRAPH_TABLE: Oracle 26ai documented; runtime gate pending.
- VECTOR/AI Vector Search: Oracle 26ai documented; runtime gate pending.
- JSON Relational Duality: Oracle 26ai documented; runtime gate pending.
- Select AI/DBMS_CLOUD_AI: Autonomous documented; package/profile runtime gate pending.
- DBMS_CLOUD_AI_AGENT: Autonomous documented; runtime/configuration gate pending.
- OML/Spatial/Text: control-plane/tool visibility and Oracle docs exist; workload-specific runtime certification pending.

Documentation availability is never recorded as runtime PASS.
