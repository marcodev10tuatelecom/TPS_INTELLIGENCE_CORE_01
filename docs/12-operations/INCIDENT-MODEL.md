# Incident Model

Incident classes: availability, performance, integrity, security, rights/compliance, AI safety, data pipeline, API, capacity and recovery.

Every incident records start/detection/recovery times, affected domains, customer/station impact, evidence, root cause, containment, corrective actions and whether canonical data/audit integrity was affected.

AI safety incidents include unauthorized tool attempt, data leakage, policy bypass, hallucinated persistence and ungrounded decision.
