# AI Emergency Disable Runbook

Triggers include suspected data leakage, policy bypass, malicious tool behavior, provider compromise, systemic hallucination or runaway cost/tool loop.

Actions: disable affected agent/task/tool/profile through an approved emergency change; revoke/rotate provider credential if exposure suspected; preserve TPS_AI_DECISION/audit evidence; route protected decisions to deterministic/manual fallback; analyze scope; retest before re-enable.

Disabling AI must not disable the canonical relational/rights/schedule authority required for basic operation.
