# Architecture Decision Record Policy

Create an ADR for every decision that materially changes data semantics, Oracle feature choice, security boundary, D3KA invariant, AI authority, API contract, performance architecture or recovery strategy.

Required fields: context, decision, alternatives, rationale, evidence, Oracle/version constraints, risks, security, performance, migration, rollback/recovery, tests, status and superseded-by.

ADR statuses: PROPOSED, ACCEPTED, DEPRECATED, SUPERSEDED, REJECTED.
