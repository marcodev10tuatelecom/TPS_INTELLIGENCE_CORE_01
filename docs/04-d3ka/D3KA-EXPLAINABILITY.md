# TPS D3KA — Explainability Contract v0.01

Any protected or user-visible intelligent decision must be explainable at two levels.

## Machine evidence

- decision/request/correlation ID;
- entity IDs;
- relation IDs and relation types;
- context IDs;
- temporal query instant/range;
- source/assertion IDs;
- policy/rule IDs and outcomes;
- vector IDs/model/version/distance when used;
- AI agent/model/tool/task versions when used;
- final authorized action or denial.

## Human explanation

A generated explanation may summarize the machine evidence but cannot substitute for it. If narrative and stored evidence disagree, evidence/authoritative records prevail and an incident is raised if material.

## Typical question

“Why did this commercial play?” must resolve campaign, creative, schedule/placement, station/channel/program context, rights/contract window, frequency/competitor policies, audience targeting if used, AI recommendation if any and the final deterministic authorization.
