# Workload Model

Representative transactions:
- resolve station/channel current schedule;
- evaluate local override + rights + commercial policy;
- ingest now-playing/playout event;
- fetch program/content metadata;
- traverse artist-track-program/station graph;
- vector similarity top-K;
- Graph RAG retrieval;
- write AI decision/audit;
- bulk catalog ingest;
- audience aggregate ingest/query.

Each benchmark defines scale factors for entities, relations, vectors, events, schedules and concurrent sessions.
