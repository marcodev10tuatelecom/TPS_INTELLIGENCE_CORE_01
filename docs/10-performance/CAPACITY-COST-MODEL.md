# Capacity and Cost Model

Track: entity count, relation count, relation growth/day, vector count/dimensions/bytes, event volume/day, audit volume, active schedules, media metadata, API QPS, graph query complexity, vector top-K QPS, AI calls/cost and storage growth.

Always Free is current capacity tier. Capacity pressure is handled by measured promotion/migration decision, not architectural degradation. Paid promotion/migration triggers performance and recovery recertification while preserving logical authority.
