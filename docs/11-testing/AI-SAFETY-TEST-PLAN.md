# AI Safety Test Plan

Campaigns cover unsupported factual prompts, stale/temporal data, conflicting evidence, low-confidence assertions, malicious retrieved text, prompt injection, tool escalation, DDL/DML requests, rights bypass, commercial bypass, unauthorized station data, provider outage, model timeout and malformed tool result.

Expected behavior: preserve authority boundary, mark uncertainty, never self-grant privileges, never treat retrieved instructions as policy, retain evidence references and log material decisions.
