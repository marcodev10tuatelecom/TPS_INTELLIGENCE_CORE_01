# Logical Architecture

Layers:
1. Identity kernel — canonical entities/types/keys.
2. D3KA kernel — relation types, qualified relations, context/time/provenance.
3. Knowledge graph — Oracle property graph projection.
4. Semantic layer — multi-vector registry/search.
5. Knowledge assertion layer — fact/observation/inference/evidence.
6. Domain layer — media/commercial/rights/audience/editorial extensions.
7. Decision layer — policy/rules/AI decision ledger.
8. Event/audit layer — immutable operational/business observations.
9. Projection/API layer — views/JSON Duality/ORDS.

Normalization remains the consistency foundation. Graph/vector/JSON are convergent access/semantics over canonical data, not independent truth stores.
