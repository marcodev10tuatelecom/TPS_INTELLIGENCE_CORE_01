# ADR-0001 — D3KA as Dominant Logical Knowledge Model

Status: ACCEPTED.

Decision: target at least 90% of eligible business knowledge/fact classes as canonical entities and qualified source-relation-target D3KA cells, physically persisted using relational integrity and projected through Oracle SQL Property Graph.

Rationale: flexible cross-domain knowledge without per-application duplication, native graph traversal, temporal/context qualification and explainable AI retrieval.

Rejected: literal dense 3D array/tensor storage, because cardinality would explode and relational integrity/queryability would degrade.
